# TMA3084_LabG01_LG1_T15

## Repository Information

This repository is created for **TMA3084 Lab Submissions**. All members of this repository belong to Assignment Group **LG1_T15**.

The purpose of this repository is to manage and submit lab assignments, allowing all team members to collaborate efficiently.

## Lab Submission Guidelines

1. Each member must create their own branch using their **matric number**.
2. All lab tasks must be completed individually unless otherwise instructed by the lecturer.
3. Members must commit and push their completed work to their respective branches.
4. After uploading their work, members must create a **Pull Request** to merge their changes into the `main` branch.
5. The Group Leader will review the Pull Requests and merge the completed work into the `main` branch as soon as possible.
6. If a Pull Request has been pending for more than **12 hours** without a response from the Group Leader, members are encouraged to contact the Group Leader directly or send a message in the WhatsApp group.
7. Any updates, announcements, or discussions regarding lab tasks will be shared through this repository or the WhatsApp group.
